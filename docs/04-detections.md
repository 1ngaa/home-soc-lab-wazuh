# Сценарии обнаружения

## 1. Ошибка аутентификации

**Правило Wazuh:** `60122`  
**Уровень:** `5`

**Цель:** проверить обнаружение события, связанного с неуспешной аутентификацией.

**Результат:** Wazuh сформировал оповещение об ошибке аутентификации. Событие отображается в интерфейсе SIEM с идентификатором правила `60122`.

## 2. Обнаружение учётных записей

**Правило Wazuh:** `92031`  
**Уровень:** `3`

**Цель:** проверить обнаружение активности, связанной с поиском информации об учётных записях Windows.

**Выполненное действие:** запуск команды `net user` для просмотра сведений об учётных записях.

**Результат:** Wazuh сформировал оповещение, связанное с обнаружением учётных записей (*Account Discovery*). В данных события отображается процесс `net1.exe`.

**MITRE ATT&CK:** `T1087 — Account Discovery`.

**Подтверждение:** [05-account-discovery.png](../screenshots/05-account-discovery.png)

## 3. Использование PowerShell

**Правило Wazuh:** `92027`  
**Уровень:** `4`

**Цель:** проверить обнаружение активности, связанной с использованием PowerShell.

**Результат:** Wazuh сформировал оповещение, связанное с запуском PowerShell. В деталях события присутствуют командная строка, родительский процесс, пользователь и хеши SHA-256. Эти данные позволяют анализировать контекст запуска и сведения о процессе.

## 5. Выводы

В лабораторной среде проверены три сценария обнаружения: ошибка аутентификации, обнаружение учётных записей и использование PowerShell.

Для каждого сценария зафиксировано соответствующее оповещение Wazuh. Идентификаторы и уровни правил позволяют сопоставлять результаты проверок, а сведения в деталях событий — анализировать контекст обнаруженной активности.

Результаты подтверждены скриншотами из лабораторной среды.
