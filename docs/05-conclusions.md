# Выводы по проекту

## 1. Результаты работы

В рамках проекта развёрнута домашняя лаборатория для изучения мониторинга и обнаружения событий информационной безопасности с использованием Wazuh SIEM.

В лаборатории настроено взаимодействие Wazuh Manager с Windows Agent и Sysmon. Для проверки отдельных сценариев использовалась Kali Linux.

В ходе работы:
- проверено подключение Windows Agent к Wazuh Manager;
- изучены события Sysmon, связанные с созданием процессов;
- проверены три сценария обнаружения: ошибка аутентификации, обнаружение учётных записей и использование PowerShell;
- проанализированы поля оповещений Wazuh;
- выполнено сканирование выбранных TCP-портов Windows-хоста с помощью Nmap.

## 2. Полученные практические навыки

В ходе выполнения проекта получен практический опыт:
- развёртывания и базовой настройки лабораторной среды на виртуальных машинах;
- работы с Wazuh Manager, Wazuh Agent и Wazuh Dashboard;
- использования Sysmon для регистрации активности процессов Windows;
- анализа событий и оповещений SIEM;
- сопоставления обнаруженной активности с техниками MITRE ATT&CK;
- выполнения базового сетевого сканирования с помощью Nmap;
- документирования конфигурации и результатов проверок.

## 3. Ограничения лаборатории

Проект представляет собой учебную лабораторию, а не промышленную систему мониторинга.

Проверены отдельные сценарии обнаружения. Результаты не означают, что лаборатория выявляет все виды атак или обеспечивает полноценную защиту инфраструктуры.

Сканирование Nmap использовалось для проверки сетевой доступности выбранных портов. Сам факт сканирования не рассматривается как подтверждённое обнаружение сетевой активности средствами Wazuh.

## 4. Возможности дальнейшего развития

В дальнейшем лабораторию можно расширить:
- новыми сценариями обнаружения и тестирования правил Wazuh;
- анализом дополнительных источников событий Windows;
- настройкой собственных правил обнаружения;
- изучением корреляции событий и расследования инцидентов;
- автоматизацией повторяемых проверок и улучшением документации.

## 5. Итог

Проект позволил на практике познакомиться с основными компонентами SIEM, сбором событий Windows и анализом оповещений безопасности.

Лаборатория может использоваться для дальнейшего изучения направлений Blue Team и SOC Analyst, а также для демонстрации начального практического опыта в портфолио.
