# Home SOC Lab — Домашняя SOC-лаборатория на базе Wazuh

## О проекте

Учебный проект по информационной безопасности, посвящённый настройке лабораторной среды для изучения мониторинга событий безопасности и обнаружения подозрительной активности.

Цель проекта — получить практический опыт работы с SIEM-системой Wazuh, изучить сбор событий с Windows и провести базовые сетевые проверки в изолированной виртуальной среде.

## Цели проекта

* Изучить основные компоненты и принципы работы Wazuh.
* Развернуть лабораторную среду на виртуальных машинах.
* Изучить сбор событий безопасности с Windows.
* Познакомиться с Sysmon и его ролью в регистрации системной активности.
* Провести сетевые проверки с помощью Nmap.
* Изучить представление событий и оповещений в интерфейсе Wazuh.
* Документировать настройки, проверки и полученные результаты.

## Используемые технологии

| Технология   | Назначение                            |
| ------------ | ------------------------------------- |
| Wazuh        | Сбор и анализ событий безопасности    |
| Ubuntu 24.04 | Операционная система сервера Wazuh    |
| Windows 10   | Исследуемый конечный узел             |
| Wazuh Agent  | Передача событий с конечного узла     |
| Sysmon       | Регистрация системных событий Windows |
| Kali Linux   | Среда для сетевых проверок            |
| Nmap         | Сканирование выбранных сетевых портов |
| VirtualBox   | Виртуализация лабораторной среды      |

## Архитектура лаборатории

Лабораторная среда включает виртуальные машины для сервера мониторинга, конечного узла Windows и проведения сетевых проверок.

Предполагаемый поток данных:

`Windows 10 → Wazuh Agent → Wazuh Server → Анализ событий`

Kali Linux используется для отдельных сетевых проверок в рамках учебной лаборатории.

## Направления исследования

* Проверка доступности выбранных сетевых портов.
* Проверка состояния компонентов Wazuh и подключения агента.
* Изучение событий Windows и Sysmon.
* Исследование событий аутентификации.
* Изучение регистрации активности PowerShell.
* Анализ событий и оповещений в интерфейсе Wazuh.

Фактические результаты каждой проверки будут описываться отдельно и сопровождаться скриншотами там, где это возможно. Перечисление направления исследования не означает, что все проверки уже завершены.

## Ограничения

Проект представляет собой учебную лабораторию в виртуальной среде. Он предназначен для изучения базовых принципов мониторинга и анализа событий безопасности и не является готовым решением для производственной инфраструктуры.
